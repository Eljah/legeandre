Причина неполной передачи: доступ к GitHub есть через подключённый API, но прямое сетевое подключение среды с файлами недоступно. API в этой сессии принимает содержимое файла строкой, без загрузки большого локального набора файлов.

Для завершения: распаковать полный пакет и запустить `SYNC_TO_GITHUB.cmd` из корня пакета. Скрипт проверит SHA-256, загрузит файлы в эту ветку обычным коммитом и сверит удалённый SHA. `main` автоматически не меняется. Токены в файлах проекта не сохраняются; используется обычная авторизация локального Git.
