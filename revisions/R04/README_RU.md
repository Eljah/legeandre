# Спим с хаски — Лежандр R04
## Откидной ПАССИВНЫЙ кожух и исследование драпировки

Открыть сначала docs/Lezhandr_R04_modeling_report.pdf. R04 — пакет CAD/численного исследования на базе R02, а не новая прошивка или аттестованный раскрой.

Изменения: подогрев рук удалён; кожух открывается вбок на 105°; две упругие дуги формируют только кожух; мягкий корпус без ног/металлической рамы. Полка, ноутбук и внешние габариты электроники восстановлены из исходного R01/R02, затем перемещены; оболочка переделана в гладкие поверхности. Ключевые ограничения в docs/LIMITATIONS_RU.md.

## Файлы
- cad/*.step: три реальные STEP-сборки (закрытый кожух / открытый / сон).
- cad/model_R04.json: все отображаемые сетки и состояния в мм.
- exchange/*_mm.obj: статические импортные сетки; не симулируемый проект CLO.
- patterns/pieces/: 29 определений лекал/лент в SVG и DXF, из них 24 предварительные панели оболочек.
- simulation/: исходные/конечные узлы, треугольники, закрепления и результаты; rejected_trials — неустойчивый первый расчёт спального покрывала.
- screenshots/: подлинные захваты X11 исполнявшихся VTK-просмотрщика и Inkscape.
- source/: воспроизводимые Python-скрипты. Все геометрические параметры задаются здесь, не в изображениях.
- tests/: журналы и машиночитаемые проверки.
- history/: исходные генераторы/параметры и хеши прежних архивов. Новые файлы не переименованы в родные форматы CLO или Rhino.

## Запуск в подходящей среде Python
Установить зависимости из requirements.txt в отдельное виртуальное окружение.

    python source/build_study.py
    python source/make_patterns.py
    python source/render_model.py
    python source/render_simulation.py
    python source/check_package.py
    python source/build_report.py

Интерактивный просмотр:

    python source/viewer.py --state open

Мышь: вращение/масштаб, клавиши 1/2/3: закрыт/открыт/сон. Текст на экране прямо указывает собственный VTK-просмотрщик, а не CLO/Rhino/Blender. Для нового расчёта после изменения свойств ткани удалите соответствующие simulation/*_drape.npz и *_metrics.json: кеш предназначен только для уже проверенных здесь параметров.

## Передача в промышленный CAD
Rhino: импорт одного STEP в мм; форма и детали, но без ExactFlat-операций. Для CLO: OBJ как статическая габаритная модель + черновые DXF для проверки импорта; единицы мм, контроль длины около 2,36 м. Совместимость DXF-диалекта с конкретной версией CLO не проверена; при необходимости использовать промежуточный швейный CAD. Швы, физические материалы и порядок сшивания нужно построить в самой системе. Пересохранение OBJ как .zprj не создаёт тканевый проект автоматически.
