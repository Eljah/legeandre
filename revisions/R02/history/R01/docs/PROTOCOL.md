# H1, ASCII, разделитель LF
Команда — одна строка до 80 байт. Поддерживаются `H1 GET`, `H1 PING`, `H1 START 34.0`, `H1 PREHEAT 34.0`, `H1 STOP`, `H1 SLEEP`. Любая другая команда отвергается. Уставка 28..37 °C, десятичная точка. Команда ARM/RESET отсутствует. Успех START подтверждается последующей телеметрией, отдельного ACK в R01 нет; не показывать в UI «нагрев включён» только по успешной отправке байтов.

```text
H1 S WORK NONE 0 25.0 25.0 25.0 25.0 25.60 12.00 100 100 100 100
```

15 токенов: H1, S, режим, код аварии, локальная готовность ARM (0/1), четыре температуры, напряжение батареи, RAW12, четыре значения PWM в процентах. `nan` означает недостоверное измерение. Контроллер проверяет 8 датчиков, но эта сокращённая телеметрия выводит первые датчики четырёх пар. На производственном этапе расширить протокол до полного массива измерений, счетчика кадров, диагностики и версии аппаратуры.

Связь: USB CDC 115200 (значение скорости виртуального порта); BLE service `f8720001-7649-4a9f-bd4e-11ee30c01001`, RX `f8720002-7649-4a9f-bd4e-11ee30c01001` (write), TX `f8720003-7649-4a9f-bd4e-11ee30c01001` (notify/read). BLE команды помещаются в 20 байт, телеметрия собирается из уведомлений по LF. Не предполагать, что одно уведомление равно одной строке. Android сериализует операции GATT.

Heartbeat PING раз в секунду; независимая от UI аренда управления 5 секунд. При наличии одновременно USB и BLE R01 не реализует эксклюзивную сессию владельца: использовать один клиент, иначе PING второго может поддерживать аренду первого. До выпуска требуется аппаратно/программно закрепить единственного владельца управления. Локальные ограничения температуры, 30-минутного сеанса и физической ARM от этого не отключаются.

Команды `SIM ARM`, `SIM SENSOR`, `SIM FOLD`, `SIM WET`, `SIM CLEAR` существуют ТОЛЬКО в loopback-симуляторе, не в MCU.
