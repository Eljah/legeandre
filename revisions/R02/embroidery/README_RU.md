# Спим с хаски — машинная вышивка R02

Рисунок взят из ранее одобренного изображения, не создан заново. `source/approved_logo_crop.png` — сохранённый фрагмент.

Открывать в программе вашей машины: `machine/Spim_s_haski_160mm.dst` либо `.exp`. Размер реальной вышивки 158,9 × 160,6 мм, 8 цветов, 52 197 проколов, 7 смен цвета и 470 запросов обрезки. Поле пялец должно быть не менее 170 × 175 мм. Файл не уменьшать до 60 мм без новой оцифровки.

Цвета назначить по `threadlist.csv`. Запросы обрезки в DST и EXP трактуются машинами по-разному; до шитья просмотреть переходы и выполнить пробу на лоскуте. Стабилизатор, нить и скорость подбираются по реальной ткани, не по этой программе. Физического отшива не было.

`logo_objects.svg` — редактируемые цветовые области, `logo_manual_stitches.svg` — явные узлы стежков. Они открыты в установленном Inkscape. Расширение Ink/Stitch не запускалось. Двоичные файлы созданы приложенным Python-оцифровщиком; это не PNG, переименованный в DST. Оба файла прочитаны независимыми декодерами, координаты всех проколов и порядок цветов совпали. SVG для повторной оцифровки не гарантирует сохранение исходного порядка обрезок; точная последовательность хранится в машинных файлах и `stitches.csv`.

`preview_from_DST.png` — линии стежков из прочитанного DST, не фотография нитей. Номера каталогов нитей не выдумывались.

Для пересборки: установить зависимости из requirements.txt полного проекта, выполнить `python prepare_logo.py`, затем `python digitize_logo.py`. По умолчанию используется включённый в комплект исходный фрагмент. Старая картинка с таблицами не используется как источник размеров, количества стежков или номеров нитей.
