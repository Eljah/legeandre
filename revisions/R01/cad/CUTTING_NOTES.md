# Заготовки R01
`stock_cutting.csv` автоматически извлечён из актуального `parts_work.csv`; ID совпадают с STEP. Телескопические опоры Txx и шарниры Hxx не включены, поскольку имеют только компоновочные тела без выпущенной рабочей деталировки.

Раскладка `stock_nesting.csv` — first-fit decreasing на условные хлысты 6000 мм, по 3 мм на каждый пропил, без выравнивания заводских торцов. Это воспроизводимый экономный вариант, но не доказанный математический оптимум. Фактическая длина хлыста, торцовка и технологические припуски должны быть уточнены. Каждая заготовка встречается ровно один раз.

Все размеры — по геометрии макета CAD. До сварки/сборки надо утвердить стыки, сплав, технологию и чертежи соединений. CSV не является разрешением резать материалы для нагружаемого человеком изделия.
