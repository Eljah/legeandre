# Межблочная распиновка
Полная таблица разъёмов платы с сетями: `connector_pinout.csv`, автоматически из электрического графа.

| ESP32-S3 | Подключение |
|---|---|
| GPIO1,2,4,5,6,7,8,9 | A2 JA1.1 ... JA8.1, 8 ADC NTC |
| GPIO10 | A2 JO1.1, батарея 100k/10k |
| GPIO11 | A2 JO2.1, RAW12 47k/10k |
| GPIO12,13,14,15 | A1 J2.1 ... J2.4, PWM зон 0...3 |
| GPIO16 | Физическая ARM, замыкание на GND, удержание >2 s |
| GPIO17 | Отдельный контакт FOLD; GND = рабочее положение и фиксация |
| GPIO18 | Контакт WET; GND = сухо/исправно, разрыв = авария |
| GPIO21 | Контакт LOOP; GND = исправна цепь безопасности |
| GPIO40 | A2 JP1.4, PERMIT |
| GPIO41 | A2 JP1.3, WD heartbeat |
| GPIO19/20 | Native USB D−/D+, зарезервированы, не GPIO управления |
| 3V3 | A2 JP1.1; питание от MCU, не 5/12 В |
| GND | A2 JP1.2, сигнальная земля A1 J2.5 |

A1 JH1 = зона 0 «туловище»; JH2 = ноги; JH3 = стопы; JH4 = руки. Пара NTC (JN1, JN2) относится к зоне 0, (JN3, JN4) к зоне 1, (JN5, JN6) к зоне 2, (JN7, JN8) к зоне 3. У JN каждый pin1 — NTC, pin2 — GND. Защита контролирует оба датчика; краткая телеметрия H1 показывает первый датчик каждой пары, а не все восемь.

JHn.2 — коммутируемый сток MOSFET, НЕ постоянная земля. Не соединять возвраты нагревателей между собой и с корпусом.

Внешняя независимая цепь реле, предохранители и ограничения USB-питания: `SAFETY_WIRING.md`.
