# Источники оцифровки, проверены 01.10.2026
- Wilcom, Mastering Satin Stitch and Tatami Stitch, 21.11.2024: https://wilcom.com/resources/blog/mastering-basic-stitch-types-satin-stitch-and-tatami-stitch — применение сатина для букв/контуров, татами для крупных полей; сдвиги рядов и пределы длины.
- Ink/Stitch, Satin Column: https://inkstitch.org/docs/stitches/satin-column/ — два рельса, контроль направления, компенсация, центральная/контурная/зигзагообразная подложка.
- Ink/Stitch, Tatami: https://inkstitch.org/docs/stitches/fill-stitch/ — объектные заполнения, направления и подложка.
- Ink/Stitch, Command line: https://inkstitch.org/docs/command-line/ — возможности движка. Этот движок НЕ исполнялся в R03; SVG содержит настройки для дальнейшего редактирования.
- Исходная композиция: пользовательский одобренный фрагмент R02 `source/approved_logo_crop.png`. Источник кривых R03 — ручная программная перерисовка по нему, не чужая библиотека готовых патчей.

Не привязаны к реальному каталогу нитей: RGB-палитра R03 является целевой, а не вымышленной картой артикулов производителя. Плотности, компенсации и толщина линии просмотра — собственные проектные параметры для пробного отшива, не нормативные значения.
