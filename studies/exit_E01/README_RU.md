# Лежандр E01 — посадка, открывание и выход вправо

[PDF: 15 листов A3](Lezhandr_E01_Exit_Sequence.pdf)

Исследование основано на сохранённой CAD-сетке R08 из ветки R09. Исходные CAD, расчёты, лекала и электроника R08/R09 не изменяются. Это не новая серийная ревизия и не инструкция для испытанного изделия.

## Что показано

11 состояний: сидящий человек; сворачивание клавиатурного клапана; выключенный нагрев и ход столика на 80 мм; открытие правой молнии; перенос плечевого укрытия влево; сбор ножного покрывала; опускание правого борта; первая нога снаружи; вторая нога; полувыпад с опорой на пол; человек стоит снаружи. Есть промежуточные положения складывания и отдельные технические виды проводки и пространства.

Ноутбук и столешница остаются на самостоятельной опоре. Низкая посадка требует подвижности человека. Показанный полувыпад — только один проверяемый габаритный сценарий, не универсальная рекомендация для пожилых людей или людей с ограниченной подвижностью.

## Новые условия, которых недостаточно в исходном раскрое

**Z05a/Z05b** — два концевых разъёма правого борта. Одна верхняя молния не освобождает его пришитые торцы. Нижняя связь остаётся тканевым сгибом; внутренние мешки с гранулами должны быть закрыты.

**Z06** — разъём левой кромки ножного покрывала, позволяющий собрать его к носку. Пришитый вдоль всей кромки пакет не может выполнить показанное движение.

Также нужны фиксаторы припаркованных укрытий, доступные плоские язычки и проверенный замок столика с контролируемым запасом кабеля. Эти дополнения **ещё не перенесены в лекала R09**.

## Метод и ограничения

Python/VTK преобразует реальные исходные треугольники CAD. Мягкий борт выделен геометрическим разрезанием сетки; отведённые детали остаются видимыми. Крупные последовательные виды используют общую камеру и масштаб. Технические разрезы явно помечены.

Положения человека заданы через суставы, без изменения длины ног. Проверяются отдельные положения: AABB-отбор близких пар и попадание вершин манекена внутрь закрытых жёстких деталей. Это **не** точная проверка всех пересечений треугольников и **не** непрерывная проверка траектории.

Складки текстиля заданы кинематически. Не рассчитаны драпировка, самоконтакт, сжатие наполнителя, трение, равновесие человека, усилия на молниях, прочность столика и нагрев. Результаты отклонённых предварительных поз сохранены в `checks/rejected_pose_summary.json`.

Текущий сценарий требует около 1,47 м справа за исходным габаритом кокона и около 0,48 м слева для укрытия, без дополнительного запаса. Это выявленное ограничение для узких балконов, а не норма минимального прохода.

## Воспроизведение

```bash
export LEZHANDR_INPUT="$PWD/revisions/R08"
mkdir -p studies/exit_E01/{checks,renders,cad}
python studies/exit_E01/source/exit_model.py
python studies/exit_E01/source/verify_sequence.py
xvfb-run -a python studies/exit_E01/source/render_sequence.py
python studies/exit_E01/source/build_pdf.py
```

Контрольная сумма `revisions/R08/cad/model_R08.json`:
`24e9297daa3b5defa1f84e015e33c6ce3ce87777a7f79eac96e84dc9689d5d0a`.

Workflow `e01-exit-sequence.yml` строит PDF и рендеры, проверяет результаты и записывает отдельные файлы только в ветку E01. Старые версии не перезаписываются. Успешный Actions подтверждает обработку файлов и ограниченные численные проверки, не готовность к эксплуатации.
