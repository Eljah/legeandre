# Лежандр / Спим с хаски

Мягкий напольный кокон для отдыха и работы с ноутбуком. Последняя CAD-конструкция — **R06**: камерная мягкая спинка без спинной рамы, локальная самостоятельная опора столика, переставляемый упор стоп и объёмное укрытие с отгибаемым клапаном клавиатуры.

## CAD опубликован

**[Открыть каталог CAD, моделей, PDF и рендеров](CAD_INDEX.md)**

В ветке `sync/r01-r06-20261002` находятся 23 STEP-сборки R01/R02/R04/R05/R06, исходники CadQuery, геометрические данные и виды. GitHub Actions добавил недостающие CAD-материалы обычными файлами и повторно открыл все сборки. `main` пока не изменён.

## Статус передачи

CAD-публикация проверена: [отчёт Actions](provenance/CAD_PUBLISH_VERIFICATION.json). Из него видны точные файлы, контрольные суммы и пределы проверки. Полную передачу всех исторических вложений разговора этот статус не утверждает; подробности — [TRANSFER_STATUS.md](TRANSFER_STATUS.md).

Материалы размещены распакованными. Для работы не требуется загружать дополнительный архив в стороннее хранилище или запускать локальный скрипт дозагрузки.

## Ограничения инженерной модели

Проект не прошёл физическое изготовление и проверку безопасности. Не завершены расчёт гранулярного наполнителя, измерение контактных давлений, полный производственный раскрой, испытания тепловой и электрической части. Геометрические сценарии посадки не являются подтверждённой эргономикой.

Механика R06, вышивка R03 и электроника/ПО R02 не образуют заново испытанную интегрированную версию. Отсутствие нагревателя рук в CAD не отключает прежний четвёртый канал прошивки. Нагрев во сне и использование прототипа под напряжением с человеком не разрешаются этой документацией. Столик не является поручнем.
