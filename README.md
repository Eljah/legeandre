# Лежандр / Спим с хаски

Инженерный проект мягкого балконного кокона: рабочее место с ноутбуком, утеплённое укрытие, регулируемые мягкие опоры и спальная конфигурация.

## Состав и полнота передачи

Материалы R01–R06 размещаются **распакованными**, каждая ревизия в своём каталоге. Состояние передачи см. в [TRANSFER_STATUS.md](TRANSFER_STATUS.md). Наличие этого README само по себе не означает, что все бинарные материалы уже опубликованы.

После полной загрузки целостность снимка проверяется командой:

```bash
python tools/verify_snapshot.py
```

Она сравнивает файлы с `provenance/SNAPSHOT_SHA256.json`. Недостающие STEP, PDF, PNG и другие файлы считаются ошибкой, а не успешной синхронизацией.

## Последние версии отдельных компонентов

| Компонент | Каталог | Статус |
|---|---|---|
| CAD, мягкая спинка, упор стоп, объёмное укрытие | `revisions/R06/` | Номинальная геометрия, не расчёт деформации наполнителя |
| Машинная вышивка | `revisions/R03/` | DST / EXP, объектный SVG, пробный отшив не выполнен |
| Платы, прошивка, настольное и Android-приложения | `revisions/R02/` | Унаследованы от R01, не полностью согласованы с новой механикой |
| Подробная история | `revisions/R01/` … `revisions/R06/` | Исходные файлы и отчёты сохраняются |

Это не одна заново испытанная интегрированная версия. Изменение геометрии не означает изменения схем и кода.

## Где искать материалы

- `revisions/` — исходники, CAD, лекала, электроника, приложения, расчёты и отчёты по ревизиям.
- `supplements/` и `attachments/` — дополнительные файлы из отдельных комплектов и вложений, которых не было в основных архивах.
- `assets/concepts_and_references/` — ранние графические концепты. Изображённые на них интерфейсы не являются доказательством запуска CAD или программ вышивки.
- `deliverables/original_archives/` — исходные ZIP в дополнение к распакованным каталогам, а не вместо них.
- `provenance/SOURCE_MAP.json` — соответствие исходных вложений и файлов архива путям в репозитории, с SHA-256.
- `provenance/ORIGINAL_REPOSITORY_README.md` — первоначальный README репозитория.

## Главные ограничения

Нет подтверждения физическим изготовлением. Не выполнены полноценная симуляция гранул, карта контактного давления, тепловые и электрические испытания готового кокона. Лекала поздних ревизий макетные и не являются полным согласованным производственным раскроем.

В позднем CAD нагреватель рук отсутствует, **но прежний четвёртый канал платы/прошивки не считается отключённым**. Нагрев во сне и испытание с человеком под напряжением не разрешаются этим проектом. Столик не является поручнем для вставания.

Ревизии сохранены без пересборки и без изменения инженерных исходников. Старые программы могут содержать пути и зависимости исходной среды. Синхронизация не является новым запуском их тестов.

## Безопасное завершение передачи

Пакет `Legeandre_Complete_Sync.zip`, переданный в беседе, содержит все материалы и `SYNC_TO_GITHUB.cmd` для Windows. Скрипт проверяет SHA-256, клонирует ветку `sync/r01-r06-20261002`, останавливается при неизвестных конфликтах, создаёт обычный коммит и выполняет push **без force**. Ветка `main` автоматически не меняется.
